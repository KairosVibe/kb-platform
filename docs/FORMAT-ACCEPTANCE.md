# 格式支持、验收基线与待确认事项

版本：2026-09-16 R3。以下是开发与验收设计，不是实测能力声明。未决项可在文档阶段确认，不能静默缩减原需求。

## 1. 文档格式矩阵

| 输入 | 当前设计处理 | 必备验收样例 |
|---|---|---|
| Markdown | UTF-8，保留标题层级、代码块及来源定位；不执行HTML/脚本 | 中文标题、嵌套列表、围栏代码、恶意HTML、空文 |
| TXT | UTF-8/带BOM；其他编码检测失败给明确错误，不用替换字符悄悄入库 | 中文、长行、乱码、空文件 |
| DOCX | 段落、标题、表格文本和可定位来源；不执行宏或外链 | 合并单元格、页眉页脚、图片为主、损坏ZIP |
| 文本PDF | 提取文本并保留页码；评测多栏和跨页顺序 | 多栏、跨页段落、表格、加密、空页 |
| 扫描/混合PDF | 必须识别无文本页面；用户已确认OCR后续扩展，首轮明确不支持扫描页，不可把空提取当成功 | 纯扫描、部分扫描、旋转、低清晰度 |
| 旧版DOC | 用户已确认旧DOC后续扩展，首轮返回不支持格式并提示转换为DOCX | 真正二进制DOC，不用改后缀DOCX冒充 |
| 图片/表格理解 | 图像语义、复杂公式、跨表计算不作首版既成能力 | 明确展示解析限制，不让模型补造数值 |

格式校验联合扩展名、MIME和文件内容；白名单不等于绝对安全。压缩炸弹、路径穿越、宏执行、任意URL抓取必须阻断；解析在资源限额内运行。损坏/加密/不支持格式返回可操作原因，不静默成功。批量逐项结果可定位到文件，授权后的原文或切片预览允许管理员检查实际提取内容。

清洗不能改变金额、否定词、单位及适用条件；切片500/50 token为起点，tokenizer版本记录。表格跨行、标题丢失等作为解析质量案例，不仅比较是否产生了chunk。偏移基于清洗文本Unicode码点，页码从1，无法可靠原文映射时original_offset=null且前端显示页级/段级定位，不伪造精确位置。

## 2. 评测运行方案

建议首轮80例，作为待批准测试计划：普通可回答30、语义改写/多轮10、无证据10、权限正反与撤权20、FAQ/缺口10。另建故障注入清单，不能混入答案准确率分母。按主题分60调参/20保留，先冻结保留集再调参，后续扩大样本时记录版本；小样本结果不得推导全行业表现。

每条案例有真实fixture语料和预期相关unit/片段；四维OR的16种布尔组合另做单测矩阵。对照关键词/向量/混合/混合+重排，所有配置使用相同授权过滤。测试集不放生产客户资料。

## 3. 已冻结的验收门槛（2026-09-16 用户确认；不是实测结果）

| 维度 | 冻结门槛 | 边界 |
|---|---|---|
| 功能 | 原180项AC逐项通过，补充接口与格式用例通过 | 有失败即记录，不用总体平均掩盖 |
| 安全 | 设计的越权、撤权、默认拒绝用例零失败 | 只证明该测试范围，不宣称绝对零漏洞 |
| 授权Recall@5 | 保留集可回答案例宏平均>=0.85 | 只在相关可读集合非空的案例计入 |
| 有据回答 | 人工核验通过率>=0.90 | 必答关键点缺失或无依据推断均计失败 |
| 引用正确 | 引用准确率>=0.95，缺失引用单独为失败 | 给出分子分母，人工双人或二次复核 |
| 无证据处理 | 标注无证据案例均不虚构具体答案 | 不可用拒答所有问题换取通过 |
| 可用性 | 干净环境完整部署及备份恢复各至少一次成功 | 不承诺生产SLA |
| 性能 | 非流式端到端P95<=8s；流式首字节P95<=2s（个人演示环境，见D-07） | 不将外部模型网络延迟排除后宣称端到端快；门槛与实测值分开报告 |

质量阈值已于2026-09-16冻结（见§4 D-06），不可测试结束再选择有利门槛；后续如需调整，必须记录变更理由、影响范围与重新验证范围。若样本少，报告通过条数而非只给百分数。无法完成双人复核时注明单人审查和偏差风险。

性能基线建议记录100份文档/约5000切片，1/5/10并发各至少100个请求，冷/暖缓存分别测；这是负载方案不是平台容量声明。分别报告首字与终态P50/P95、错误率、FAQ精确/语义链路及各模型调用用量。**本表为门槛，下列数值为待实测目标，不得表述为已达成。**
