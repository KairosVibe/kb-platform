# 复用说明：当前有效结论

更新：2026-09-16。本文替代旧复用说明；旧文件归档，旧工期和选型判断不继续作为依据。

## 路线

原General-PurposeRAG可作为渐进改造候选基线，也可作为组件来源。当前不再锁定“只读参考、只允许少量移植”。原目录本轮仍保持不变；开发需在隔离副本/分支中进行。详见 [复用与改造矩阵](REUSE-MATRIX.md) 和 [ADR-0004](adr/ADR-0004-reuse-baseline.md)。

## 本次核对发现

- 模型适配、Milvus检索、切片、Vue上传/流式和测试脚本均存在源码，有复用价值。
- rerank失败退Mock、搜索异常跳过、SSE坏JSON忽略及无seq处理，不满足R3，不能直接移植。
- 身份依赖X-Role和可空API Key，必须替换为服务端身份与四维授权。
- 当前切片接口是POST并硬编码default_chunks；当前dashboard已带API Key依赖，旧说明的接口方法与“无鉴权”描述修正。
- 文本解析器直接UTF-8读取且忽略错误，只可作为TXT/MD起点，不提供DOCX/PDF解析证明。

## 撤回旧的无证据结论

旧“直接移植即可”“净节省1.8—3人日”“固定兼容某些SDK版本”“全部平台均无某能力”等绝对化表述不作为当前结论。必须以选定版本、运行基线与需求差异验证。

旧第三方选型中的许可证和能力比较未在本轮重新核验，不用于否决路线；也不把组织多部门直接等同于多租户SaaS。当前只记录本地LICENSE内容，实际复用保留来源，依赖/素材另行核验。

历史文件缺失只能说明当前快照不含该模块，不能不检查调用路径就断言所有相关端点必然500。相似地，有tests目录不等于测试通过，有锁文件不等于当前环境可启动。
