## 1. 横向约束

- 登录且启用；功能码后端强制检查。四维OR采用直属部门精确匹配，无创建者/超管读权旁路；全空拒绝。
- 管理台账最小元数据属于kb:view能力；正文另需数据读权。普通问答受限提示只有固定message，不含ID标题或ACL名称。
- 多来源FAQ/历史须每个来源可读；缓存不缓存永久放行。权限提交后新读取和输出批次复核，已传输内容不能撤回。
- 错误：401身份、403功能/读权、404归属不符或不存在、409版本冲突、413大小、415格式、422参数、429限额、503依赖。响应不带密钥或受限正文。
- 所有页面包含加载、空态、无权限、失败、重试；写请求禁止重复提交；revision冲突先刷新再由用户重新确认内容。
- 14个功能码：ai:ask、kb:view、kb:upload、kb:edit、kb:delete、kb:perm、faq:review、faq:publish、gap:handle、dashboard:view、sys:user、sys:role、sys:dept、sys:model。

## 1.1 页面与交互层级

1. 登录页：用户名/密码/提交/错误反馈；刷新令牌失败回登录，不丢弃非敏感草稿。
2. 组织配置页：部门树→用户分页/启停→角色功能树；各面板按sys:dept/sys:user/sys:role独立授权。
3. 知识中心：台账/卡片→导入抽屉→逐文件上传/解析进度→详情与切片→四维权限弹窗；列表返回后保留筛选和页码。
4. 问答工作台：本人会话侧栏→智能联想→输入/发送/停止→流式Markdown与代码复制→引用卡→固定受限提示；恢复状态与生成状态分开显示。
5. 沉淀运营页：候选FAQ→编辑/审核→已发布FAQ与缓存开关；缺口列表→转建补充任务→绑定文档→回放验证。
6. 运营看板：日/周选择→访问摘要→知识总量→高频问题→引用热度→用量趋势→延迟分布；数字带样本数和口径说明。
7. 模型配置面板：模型/阈值/频次/限额→保存版本→探测；密钥仅显示已配置，不回显。

## 1.2 数据生命周期与一致性验收

1. 知识：index_status=pending/indexed/stale；enabled和is_deleted独立。替换或切片变更增加content_version，旧索引不可用于新回答；只有indexed_version=content_version才放行检索。
2. 索引任务：queued→running→succeeded；瞬时失败running→retry_wait→running；永久或耗尽失败→failed；过时版本→superseded。stage=parsing/embedding/indexing只表示阶段，不混进status。
3. 问答请求：accepted→running→completed/rejected/failed/cancelled。result_type区分answered/faq_hit/access_restricted/no_evidence/low_confidence/service_error；请求状态与业务结果不是同一字段。
4. FAQ：candidate→published或rejected；published→offline；来源失效→stale；offline/stale重新审核前转candidate。开关cache_enabled不改变审核状态。
5. 缺口：open→processing→closed；关联补充任务是独立实体，不能用knowledge.index_status=processing表示。
6. 授权变更生效点：数据库事务提交；运行流发下一批之前重新判断。执行锁不能跨网络等待；已发数据不作追溯删除承诺。
7. 双写验收：分别在DB提交前后、向量部分写入、激活前、删除后注入故障；不可出现旧版本激活或删除后复活。相同任务重跑不增加有效向量数量。

## 1.3 指标口径与输出格式

1. PV：唯一接受的问答请求数，含FAQ、拒答、后续失败；不含未认证请求及幂等重发。UV按这些请求去重用户。
2. FAQ命中率=成功直出请求/PV；覆盖率=(有效FAQ+有足够授权证据的RAG回答)/PV。纯检索召回率另列，不再混用覆盖率。
3. 知识数=未删除单元数，另分启用/已索引；热度按每轮每单元去重引用；高频提问使用规范化问题和时间窗口。
4. 用量分生成prompt/completion、embedding、rerank；已知没有调用记0，未知记null并计unknown数量。FAQ语义匹配可能有embedding成本。
5. 延迟分别记录首字与终态耗时；成功与失败分桶，空样本为null；日/周使用Asia/Shanghai半开时间区间。
6. 问答审计保留原需求九项，扩展request_id、状态、结果类型、来源版本和用量状态；FAQ卡包含簇/频次/来源/答案/置信度；缺口包含问题/部门/近期频次/最高相似度/建议分类/时间。

## 2. 逐模块产品拆解

### M01 身份认证

- 角色：普通用户。
- 原需求：2.9.2/2.9.6/2.9.10。
- 服务模块：auth_svc。

- **US-01.01 登录**
  - **用户故事**：作为普通用户，我希望登录，以便完成本模块业务并获得可核对结果。
  - **入口与前置**：POST /api/auth/login；公开；对象存在且满足归属约束，内部任务须已持久登记。
  - **主流程**：校验限流；查账号验证密码及启用状态；建立持久刷新会话；签发两类令牌。
  - **验收标准**：
    - AC-01.01-01 正常：正确凭据登录成功；错误凭据统一401。
    - AC-01.01-02 边界/失败：停用401；超限429；密码超72字节显式拒绝，不截断。
    - AC-01.01-03 一致性：返回字段满足函数输出契约；写操作结果可查询复核，重复/并发执行按本条幂等或revision规则处理，纯查询不改变业务状态。
  - **边界条件 BC-01.01**：停用401；超限429；密码超72字节显式拒绝，不截断；遵守公共错误与无权限处理。
  - **输出字段**：access_token:str,refresh_token:str,expires_in:int。
  - **函数追溯**：F-01.01 auth_svc.login。

- **US-01.02 刷新**
  - **用户故事**：作为普通用户，我希望刷新，以便完成本模块业务并获得可核对结果。
  - **入口与前置**：POST /api/auth/refresh；有效刷新会话；对象存在且满足归属约束，内部任务须已持久登记。
  - **主流程**：验签与用途；锁定持久刷新会话；检查账号；一次性消费旧令牌并签发新令牌。
  - **验收标准**：
    - AC-01.02-01 正常：并发刷新仅一个成功，旧令牌不可重放。
    - AC-01.02-02 边界/失败：重启后撤销仍生效；存储异常503。
    - AC-01.02-03 一致性：返回字段满足函数输出契约；写操作结果可查询复核，重复/并发执行按本条幂等或revision规则处理，纯查询不改变业务状态。
  - **边界条件 BC-01.02**：重启后撤销仍生效；存储异常503；遵守公共错误与无权限处理。
  - **输出字段**：access_token:str,refresh_token:str,expires_in:int。
  - **函数追溯**：F-01.02 auth_svc.rotate_refresh。

- **US-01.03 退出**
  - **用户故事**：作为普通用户，我希望退出，以便完成本模块业务并获得可核对结果。
  - **入口与前置**：POST /api/auth/logout；登录态；对象存在且满足归属约束，内部任务须已持久登记。
  - **主流程**：验证归属；撤销会话；停止该会话活动请求；客户端清理身份。
  - **验收标准**：
    - AC-01.03-01 正常：退出后该会话两类令牌失效。
    - AC-01.03-02 边界/失败：重复退出幂等；其他设备会话不受影响。
    - AC-01.03-03 一致性：返回字段满足函数输出契约；写操作结果可查询复核，重复/并发执行按本条幂等或revision规则处理，纯查询不改变业务状态。
  - **边界条件 BC-01.03**：重复退出幂等；其他设备会话不受影响；遵守公共错误与无权限处理。
  - **输出字段**：revoked:bool。
  - **函数追溯**：F-01.03 auth_svc.logout。

- **US-01.04 当前身份**
  - **用户故事**：作为普通用户，我希望当前身份，以便完成本模块业务并获得可核对结果。
  - **入口与前置**：GET /api/auth/me；登录态；对象存在且满足归属约束，内部任务须已持久登记。
  - **主流程**：读取当前账号状态、直属部门、角色与权限码；生成最小身份视图。

    - AC-01.04-02 边界/失败：无部门返回null；账号停用401。
    - AC-01.04-03 一致性：返回字段满足函数输出契约；写操作结果可查询复核，重复/并发执行按本条幂等或revision规则处理，纯查询不改变业务状态。
  - **边界条件 BC-01.04**：无部门返回null；账号停用401；遵守公共错误与无权限处理。
  - **输出字段**：user_id:int,username:str,dept_id:int|null,role_ids:list[int],permission_codes:list[str],revision:int。
  - **函数追溯**：F-01.04 auth_svc.get_me。
