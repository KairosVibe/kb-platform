# ADR-0003：通用平台契约闭合与图文同步

日期：2026-09-16。状态：提议，等待文档确认；没有业务代码实施。

## Context

用户确认目标是通用知识管理与问答平台的工程落地和简历展示，并要求先补齐文档。旧图尚未同步；函数稿存在登录前功能鉴权、游标先提交、终态后事件存在崩溃窗口、批量响应缺逐文件标识、缺少用户列表与补档绑定接口等问题。

## Decision

保留原10模块60功能与14功能码，采用7张有明确范围的图，配套API、数据实体和验收规范。补充页面所必需的只读列表/绑定入口；终态和最终事件同事务、发送在事务之后；异步缺口用持久outbox。前端处理事件成功后才提交游标；登录/刷新按独立凭据校验。当前只更新设计。

## Alternatives

仅在图上加免责声明不能解决错误流程；提前开发再补契约会将权限、幂等和恢复歧义写入代码。拆微服务或加入电商业务均不服务当前目标，不采纳。

## Consequences

增加文档和后续持久化实现工作，但避免接口缺页、重复消费和丢终态。7张图为概览和细节分解，省略调用必须在图册说明，不可把省略误读为无鉴权。格式、模型、环境及数值门槛仍须用户确认。

## Migration / Compatibility

原F/US编号不重排；补充接口API-S编号并映射原模块。批量结果补字段，get_task补revision，Location允许original_offset为空，FAQ补resubmit；涉及前后端DTO共同对齐。数据库尚未迁移，逻辑实体不冒充上线表。旧图与被改文档先归档，JSON与HTML同步替换。

## Rollback

可从归档恢复文档，但旧权限旁路、缺口丢失等已识别问题不能重新成为开发依据。若仅图表显示失败，保留最新契约并标明图待修；不把旧图重新标为通过。

## Validation

图源结构/几何、HTML交付哈希、桌面尺寸显示、Markdown链接、F/US编号与接口路径映射分别记录。未运行业务测试、数据库迁移、模型评测；相关结果仅在开发阶段产生。

## 用户确认补充

2026-09-16用户确认首轮DOCX/文本PDF/Markdown/TXT，DOC/OCR后续扩展；演示采用云端模型API和模拟资料。该确认不等于批准开始开发，也不等于指定具体模型或接受所有拟议验收阈值。
